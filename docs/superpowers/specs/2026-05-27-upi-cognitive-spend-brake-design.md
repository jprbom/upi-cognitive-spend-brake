# UPI Cognitive Spend Brake Design

## Product Thesis

A behavioral AI system that detects impulse risk, UPI Lite micro-spend leakage, late-night drift, category overuse, and self-control rule violations, then adds only the minimum useful payment friction.

## UX

The first screen is a usable role-aware product console, not a landing page.

## Backend

Express provides validated APIs, demo RBAC, rate limits, security headers, synthetic persistence, and a domain decision engine.
